About IFC Federator

IFC Federator is a BIM coordination utility for importing multiple IFC models, reviewing them together in a federated viewer, and exporting a source-preserving combined IFC file.

The app is designed for IFC coordination workflows across architecture, structure, MEP, civils and other discipline models.

Core Features

  • Import multiple IFC files.
  • Preview models together in a federated 3D view.
  • Track loaded, visible and hidden models.
  • Use Fit All and Fit Selected to navigate the federation.
  • Toggle model visibility.
  • Export multiple same-schema IFCs as one combined IFC file.
  • Generate a secondary CSV coordination report.
  • Use the AI Coordination Assistant for plain-English guidance based on app-generated model facts.

How Combined IFC Export Works

IFC Federator creates a source-preserving combined IFC file. It keeps source geometry, placements, GUIDs, properties and relationships as far as possible, while safely renumbering STEP entity labels to avoid collisions between source files.

For V1, the app requires compatible IFC schemas for export. Mixed-schema exports, such as combining IFC2X3 and IFC4, are blocked with a user-facing message.

Troubleshooting

My models do not appear aligned

IFC Federator preserves the source IFC placements. It does not automatically rewrite coordinates or remodel storeys. If models are far apart, check project coordinates, shared origin, units and authoring/export settings in the source BIM tools.

Export is not available

Combined IFC export requires at least two successfully imported, same-schema IFC files. If one file is invalid or uses a different schema, the app will explain the issue.

The viewer looks empty

Use Fit All or select a model and use Fit Selected. Very large coordinate systems can require camera refitting.
