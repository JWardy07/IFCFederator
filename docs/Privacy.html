IFC Federator Privacy Policy

Last updated: 8 July 2026

```

Overview

IFC Federator is designed as a local-first BIM coordination app. The app lets you import IFC files selected by you, review them in a federated viewer, and export a source-preserving combined IFC file.

We do not sell personal data. We do not use third-party advertising SDKs. We do not require an account to use the app.

Data Collection

IFC Federator does not collect, transmit or sell personal data from the app.

The app does not include external analytics, advertising tracking, or third-party marketing trackers.

IFC Files and Project Data

IFC files are selected by you using the system file picker. The app reads those files locally so it can analyse, display, federate and export IFC model data.

Imported files may be copied into app-controlled local storage so the app can manage the active federation session. Exported files are saved or shared only when you choose to do so using system save/share features.

Your IFC files are not uploaded to our servers by IFC Federator.

AI Coordination Assistant

IFC Federator includes an AI-ready coordination assistant. The assistant explains app-generated facts such as loaded model count, schema compatibility, export readiness, model visibility and coordination warnings.

Where Apple Intelligence or Foundation Models support is available, the app may use Apple-provided on-device capabilities. Where it is not available, the app uses a deterministic local fallback summary. The assistant is not a certified validation engine and does not replace professional BIM review.

The app does not use external paid AI APIs.

iCloud, Files and Third-Party Storage Providers

If you choose files stored in iCloud Drive, Files, or another document provider, those services are controlled by Apple or the relevant provider. IFC Federator only accesses files you select and only for app functions such as import, review and export.

Security-Scoped File Access

On Apple platforms, the app may use security-scoped access to read files selected through the system picker. Access is used only to import or process the files you choose.

Children's Privacy

IFC Federator is intended for professional and educational BIM/model coordination use. It is not designed to knowingly collect data from children.

Changes to This Policy

This privacy policy may be updated from time to time. Any changes will be reflected in the updated policy text.
```
